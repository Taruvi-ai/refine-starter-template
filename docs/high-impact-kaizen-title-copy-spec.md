# High Impact Kaizen Simplified Page

## Request

Change the Quarterly High-Impact Analysis page heading to High Impact Kaizen and keep the page simple by removing unwanted options such as export.

## Fix

- Updated the page header title in the governance page.
- Removed the page-level Export Selected action.
- Removed the KPI summary strip, chart, and analysis archive card list from this page.
- Removed the Top N and Minimum Score controls from the generate toolbar.
- Removed the Report dropdown from the ranked list area.
- Changed the ranked list to follow the selected Year and Quarter controls.
- Replaced the archived analysis title/date line with a simple selected-period line.
- Kept the core Generate controls and the ranked Kaizens table.
- Left routes and data resources unchanged.

## Acceptance

- The page heading displays "High Impact Kaizen".
- The page no longer shows an export option.
- The page no longer shows Top N or Minimum Score inputs.
- The page no longer shows a Report dropdown.
- The ranked Kaizens list updates based on selected Year and Quarter.
- The ranked list subtitle shows the selected period instead of an archived analysis title/date.
- The page presents a simpler generate-and-review workflow.
